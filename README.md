# 🚀 Automation Engineer Portfolio

A highly sophisticated, end-to-end **Internship Work Tracker and Developer Profile** built to showcase quantifiable business impact, automated data pipelines, and full-cycle software engineering.

## 🌟 Features

- **Dynamic Content Engine:** Seamlessly parses Markdown logs to render an aesthetic, chronological timeline of engineering workflows and architectural decisions.
- **Quantifiable ROI:** Animated metrics dashboard showcasing total automated hours saved, lines of code, and deployed projects.
- **Code Highlights:** Embedded, syntax-highlighted IDE-style code blocks for showcasing complex algorithms (e.g., Self-Healing RPA, Aggressive Date Parsing).
- **Sophisticated Developer Profile:** A sleek, editorial-style layout detailing my technical arsenal and professional engineering focus.

## 🛠️ Core Engineering Stack

* **Frontend:** React, Next.js 14, Tailwind CSS, Framer Motion
* **Automation:** Node.js, Playwright
* **Backend & Integrations:** Google Apps Script, Google Sheets API, Python
* **Deployment:** Netlify

## ⚙️ Getting Started

To run this portfolio locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live tracker.
